# v5.0.0 — Automatic visual treatment / 默认图形、字体与配套素材

The skill now turns a semantic plan into supported visual forms, installed typography, matched icons and real image requests. A user can give materials and ask for a professional deck without listing layout coordinates, fonts, chart APIs or individual icon prompts.

新版将内容计划落实为可执行的视觉构成。用户给材料并要求制作专业 PPT 即可，无需填写坐标、字体、图表 API 或逐枚图标提示词。

![Actual exported pages / 实际导出页面](https://raw.githubusercontent.com/bingxijun/ppt-design-polish/v5.0.0/docs/assets/visual-defaults-showcase.jpg)

- **Analytical graphics / 分析图：** ranking, time trend, share of a named whole, distribution, paired comparison and reconciled contributions. 排名、时间、占比、分布、前后对比和贡献拆解分别匹配条形、折线、环形、连续柱、哑铃与瀑布表现。
- **Relationship diagrams / 内容图解：** different native process, cycle and hierarchy geometry. 顺序、循环和父子结构采用不同的原生关系布局。
- **Typography / 字体排版：** installed CJK/Latin families, title/body/numerical hierarchy, quiet body ink and short-line rebalancing. 选择实际字体，区分标题、正文与数字；正文保持中性墨色，尝试改善过短末行。
- **Coherent icons / 统一图标：** 24 pinned, licensed Lucide SVGs; semantic matching in Chinese/English and offline color-consistent image assets. 24 枚固定版本授权图标，按中英文含义匹配并统一视觉语言。
- **Actual imagery / 实际配图：** generated asset briefs include composition, subject placement, text-safe space and palette. The host executes real image/source tools; missing files block composition. 配图要求自动补全构图与留白，由宿主实际生成或取图；真实产品身份继续使用授权原图。

The new nine-page fictional ARC / 弧光 example has no font names or page coordinates in its original plan. Its hero and matching material close-up were generated with built-in imagegen; all final pages were inspected. Three charts retain workbook data; dumbbell/waterfall and relationship diagrams use editable native shapes/text/connectors. Photos/icons remain replaceable images.

九页新案例的高层计划无需字体名称或页面坐标，主视觉与独立材质特写由实际生图工具完成。三张图表带工作簿数据；其他分析图解、流程和结构由原生可编辑对象组成。

**78 functional tests passed**, with source/content checks and actual exported-page inspection. The tests check data and output behavior, not a beauty score. Independent human aesthetic review remains pending; the project does not promise universal quality or unrecognizable AI involvement.

**78 项功能测试通过**，并检查来源、内容约束和实际导出。测试保障数据及输出行为，不给审美打分；独立人工审美评审仍待完成，不宣称百分百质量。
