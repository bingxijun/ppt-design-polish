# v5.1.0 — Whole-page defaults / 封装整页视觉效果

5.0 selected charts and icons, but its body pages repeated similar heading/graphic layouts. 5.1 adds complete page compositions: typography, image proportions, analytical figure, labels, surface and functional details are resolved together.

5.0 会选择图表与图标，正文构图仍重复。5.1 将字体、图文比例、分析图、标注、背景层次和细节封装为完整页面配方。

![Same source, data and images / 相同材料、数据与配图的实际对照](https://raw.githubusercontent.com/bingxijun/ppt-design-polish/v5.1.0/docs/assets/v51-same-input-comparison.jpg)

- **Page recipes / 整页配方：** product/material spreads, ranking readouts, three-column share pages, endpoint trends, numbered process rails and editable evidence diagrams. 产品材质页、排名读数、占比三栏、趋势末期读数、编号流程及原生分析图解。
- **Complete appearance descriptions / 完整视觉描述：** `visual-brief.json` describes each supported page for the native builder or a host backend. 同时支持宿主按整页描述执行。
- **Automatic activation / 默认启用：** new semantic plans do not need a special activation flag. Supplied design systems and templates keep priority. 新计划无需额外开关，明确的品牌和模板优先。
- **Fresh builds / 当前计划重建：** building a semantic workspace prepares icons and recompiles the current plan before export. No silent stale `deck.json`. 修复改计划却继续构建旧页面的问题。
- **Typography and assets / 字体与素材：** installed display/body pairing, Chinese headline word boundaries, light/dark semantic icons, native pie option and existing grounded data checks. 标题正文组合、中文标题断词、明暗图标与原生饼图。

The new nine-page ARC example uses exactly the same claims, numbers and two images as 5.0, without font names or page coordinates in the high-level plan. All exported pages were inspected. This is a concrete version comparison, not an independent human aesthetic benchmark or a universal quality guarantee.

九页案例沿用完全相同的内容、数值和两张图片，高层计划不填写字体或坐标；实际导出已逐页查看。本例是版本对照，不冒充独立人工审美结果，不承诺百分百质量。
