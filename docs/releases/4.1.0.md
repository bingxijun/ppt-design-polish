# v4.1.0 — Design proofs & visual revision / 打样、选稿与看图返工

Make important design choices visible and reviewable. The skill now keeps real rendered alternatives, a reasoned selection, and located before/after revisions alongside the editable deck.

让关键设计决策可见、可检查：保存真实导出的候选页面、选稿依据，以及带位置的修改前后图，并保留可编辑的 PPTX。

![Actual rendered revision / 实际导出的返工对照](https://raw.githubusercontent.com/bingxijun/ppt-design-polish/v4.1.0/docs/assets/studio-revision.jpg)

- **Design study / 设计打样：** `studio.py` freezes candidate PPTX and page images, checks matching source/content contracts, records strengths and tradeoffs, and invalidates stale decisions. Approved references can use one proof; small edits keep a lighter route. 保存候选稿、检查材料和内容约束一致性、记录优点与取舍；材料或文件变化会使旧决定失效。已确定的参考样式支持单份打样，小改字保留轻量路径。
- **Located revision / 定位返工：** critique records include the slide, visible problem and bounding box. A fixed issue requires a changed deck and changed affected page pixels; serious unresolved issues block delivery. 复查记录包含页码、可见问题及位置；修复必须对应变化后的文件和受影响页面，严重问题未处理时阻止交付。
- **Reader review / 读者评审：** `blind_review.py` prepares randomized anonymous comparisons and a blank feedback form. It summarizes submitted decisions without inventing scores or claiming reviewer independence. 自动生成随机左右顺序的匿名对比包和空白反馈表；只汇总真实提交的意见，不伪造评分或声称已验证评审者独立性。
- **Real example / 实际案例：** six editable Chinese exhibition slides, three proof groups with two alternatives each, and five documented visual fixes. 中文展览提案共六页，正文、数据、密集信息三组双方案打样，记录并修复五处实际可见问题。生成的虚构展厅配图附有提示词与来源记录。
- **Rendering fixes / 渲染修复：** page furniture now stays above full-bleed images; horizontal bars support intentional category order; route diagrams support native arrow connectors. 修复全幅图片遮挡页脚说明，支持横向条形图的类别顺序及原生箭头连接线。

**Validation / 验证：** 63 automated tests passed, together with native chart/table, source-contract and frozen-evidence checks. The example was visually inspected and revised by the authoring agent. **Independent reader review is pending: 0 decisions.** The public comparison is a tooling demonstration, not a held-out benchmark or proof of universally better taste. No promise of 100% quality or “zero AI look.”

63 项自动测试，以及原生图表/表格、来源约束和冻结证据检查通过；制作代理已看图复查并返工。**独立读者评审待完成，目前为 0 条决定。** 公开对比用于演示工具，并非未见材料上的独立测试，不代表已经证明普遍的审美优势，也不承诺百分百质量或“零 AI 痕迹”。
