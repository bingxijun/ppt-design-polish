# 美术与版式决策

## 判断问题，而非识别作者

“AI 味”是用户对结果的观感描述，不是可靠的来源鉴定。一个手工制作的 PPT 同样可能多色、拥挤、同质。改动要落在可观察问题上：

| 现象 | 应核实的原因 | 有效改法 |
|---|---|---|
| 一句有许多颜色 | 是否表示不同语义，是否抢走阅读顺序 | 正文归一，保留有理由的重点；先用字重和位置区分 |
| 每页三个等大卡片 | 内容是否真的并列、重要程度是否相同 | 按比较、因果、时序或主次重排；需要对等比较时保留等大结构 |
| 背景很炫但内容难读 | 主体、纹理、光效是否占据文字区 | 换构图、裁切或用平静底色；遮罩只作辅助 |
| 信息很多却没有中心 | 是否把原文逐段搬上画布 | 建立阅读路径，拆出证据/解释；保留所有必需事实 |
| 大量空洞图标 | 图标是否增加识别或解释价值 | 移除，给证据或内容让出空间 |
| 每页都像网页面板 | 是否机械复用了组件布局 | 改成页面级构图，用网格组织文字与证据 |
| 极简但什么也没说 | 是否删掉数字、对象、比较条件 | 恢复有效信息，让简洁服务理解 |

先找主因。不要同时套用所有规则，避免把原有品牌稿全部洗成单调黑白稿。

## 选择有依据的方向

从材料确定方向，而非随机挑“高级风”：

- 科研汇报：图表、方法与证据主导，图片服务解释，细节和引文能读清。
- 经营决策：结论与比较先被看到，数据口径紧邻证据，重点有层级。
- 产品/空间/制造：产品原图、界面或现场素材建立具体性，裁切有目的。
- 文化/教育/品牌：可用更强图片、色彩与字体个性，但同一套图像语言贯穿全稿。

这些是判断线索，不是强制模板。保留有意的高密度、鲜明配色或纯文字表达。

有参考时提取可操作变量，例如“标题窄列左对齐、正文与证据共基线、实拍图片低饱和、图注靠近图片”，不要只写“苹果风、咨询风、杂志感”。不要把参考中的专有图案、标志、文字当成可自由复制素材。

## 先建立角色，再定数值

设计变量应当能回答“为什么不同”：

- 颜色：背景、正文、辅助、强调、类别/状态。默认中性底、主文字色与少量强调色；有多系列数据时按辨识需求增加颜色。颜色不能是唯一编码方式。
- 字体：优先一套有完整语言覆盖的字体，用字号/字重区分；品牌或参考需要时可做字体搭配。不要把拉丁字体名称当作中文字体可用的证据。
- 字号：依据使用场景。16:9 投屏稿可从标题 30–40pt、正文 20–26pt、图注 12–16pt起步，再按实际渲染和观看距离调整。独立阅读稿可能更密；用户模板优先。这些范围不是通过条件。
- 网格：固定主要边距、列关系与对齐锚点，必要时允许跨列。标题、主图、图注之间要有关联，避免浮动碎片。
- 密度：由任务决定，避免为填满页面补文案，或为追求留白删证据。

只有主内容需要时才安排副标题、眉题、页脚。不要形成标题、眉题、副标题、卡片标题、卡片小标题、底部结论六层同时争抢的页面。

## 内容关系决定版式

| 沟通任务 | 优先考虑 | 常见误用 |
|---|---|---|
| 两种方案比较 | 相同维度、共享基线、直接对照 | 两边各写不同维度，看似比较却无法判断 |
| 随时间变化 | 带单位和时间轴的趋势图、必要注释 | 用几张风景图代替变化证据 |
| 流程 | 阶段、方向、依赖与异常路径 | 用三个孤立图标隐藏真实先后关系 |
| 系统/组织 | 结构层级、连接和边界 | 所有东西画成同等卡片，连接含义不明 |
| 场景/对象展示 | 具体图片或界面为主，标签贴近对象 | 不相关的“科技感”通用图占半页 |
| 单一观点 | 有意的文字构图、足够证据或具体例子 | 硬加装饰图才能“满足有图” |
| 表格查阅 | 原生表格、稳定对齐、行列分组与重点 | 把每个单元格变成高饱和彩色面板 |

重复布局可以支持连贯比较。只有内容任务发生变化时才变化构图，不追求随机多样化。

## 示例：不靠换皮修复一页

输入页：“本季度进展”，三个彩色卡片写“营收增长、成本优化、未来展望”，每句若干关键词着色，右上角机器人图。

先问原材料是否有可比数据。有数据时，可能将营收与成本放在共享时间范围的原生图表中，把下一步动作放在独立短段落中；保留数字、币种、期间和来源。没有数据时，不编百分比，只重排真实信息，用标题与字重表达主次。机器人图与材料无关就移除。

这次改动的理由是信息可以比较、阅读路径清楚，不是“黑白比彩色高级”。
