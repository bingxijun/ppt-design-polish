# 图片与生图指导

## 图片的职责

先选职责，再选工具：

| 职责 | 素材优先级 | 使用方式 |
|---|---|---|
| 真实证据 | 原始照片、产品图、论文图、实验或界面截图 | 保留含义、出处、必要标签，避免误导性裁切 |
| 解释抽象关系 | 原生图表/可编辑图解；必要的插画 | 文字和关键关系保留可编辑；插画不代替数据 |
| 建立场景或情绪 | 相关实拍、合适的生成图 | 主体具体，风格一致，避免通用机器人/握手/发光网络 |
| 背景与纹理 | 平静底色优先；有理由再加图片 | 给文字留出安全区，不让纹理争夺阅读注意力 |

“与主题关键词相关”不等于有用。问：拿掉它后，理解、证据或情境是否损失？如果没有，可以不用图。封面、章节页可以为情绪使用图片，不把这项例外推广到所有正文页。

## 构图早于生图

调用图像工具之前，确定：

1. 插入框比例与实际展示大小，而非只用全稿 16:9。
2. 主体位于哪一侧、视线或运动方向；需要保留的边界。
3. 哪个区域给标题/正文，那个区域应当低细节、亮度稳定。
4. 与整稿一致的摄影/插画风格、光线和色调。
5. 哪些元素必须真实、不能生成；文字/数字是否另用原生对象叠加。

提示词示例（仅适用于假想的工业场景插画，不表示真实厂房）：

> 生成横向 4:3 的编辑插图，用于介绍工厂设备维护。设备主体集中在右侧约六成区域，左侧保持大面积低细节浅灰墙面，供后期放置原生标题。自然侧光，朴素真实的工业材料，避免霓虹、科幻 UI 和过度光泽。不要文字、数字、标志、水印。不要表现为某家真实工厂的纪录照片。

涉及透明抠图时，用工具的透明背景选项；不在提示词里写“透明”就假设文件已有 alpha 通道。不要在没有引用图片的情况下声称保留了用户产品外形。

## 分层合成

推荐层次为：底色 → 照片/插画 → 必要的局部遮罩 → 原生文字/图表/标签 → 必要图注。

- 无图层级也可以：底色 → 原生文字与证据。
- 不将关键标题、标签、数据或段落烧进背景图；它们需要校对、换语言和后续修改。
- 纯照片页或用户指定的图像式作品可以整页铺图。用户要求图片式幻灯片时，明确其编辑限制。
- 不用复杂图片加重遮罩来长期补救构图错误；优先重新裁切、换图或改版式。
- 在缩小到幻灯片实际大小后检查图片。高分辨率不等于有效构图，也不能修复对象错误。

## 选择、复查与替代

用用户原图时保留未改动的原文件；修图采用副本。外部素材记录来源、许可/使用约束中已知的信息，按环境要求标注；不猜测其可商用。

生图后实际看图：主体是否对、是否误导为真实证据、是否出现畸形、假文字、伪商标、错误结构；插入版面后再检查裁切、文本安全区与全稿一致性。

若工具或素材受限，先完成原生图表和文字构图；存在合适来源时再找图。只有少量必要素材缺失时报告具体缺口，不以通用装饰图填满页面。
