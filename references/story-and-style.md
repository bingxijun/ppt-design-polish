# 内容策划、参考设计与主题复用

## 先建立真实信息

新稿先读材料，按任务寻找事实缺口；只有需要时才搜索外部来源。建立可追溯的事实、数字、计算与引用。图表保留源数据与计算过程。没有证据时不为了“像咨询报告”制造百分比、市场规模或因果结论。

逐页明确沟通任务与所需证据。演讲稿强调观看距离、少量主线和讲述衔接；独立阅读稿需要足够上下文与可查阅细节。两者不能机械共用密度标准。页数包括封面在内，除非用户另有定义。

叙事顺序来自问题本身：需要决策时，可按问题、证据、选项与行动组织；解释知识时，可按对象、机制与例子组织。不要为套结构添加原材料没有的章节。概述/定义页可以用主题标题，发现页才用有证据的结论标题。

## 统一设计变量

工作区的 `design-plan.json` 是简短可恢复记录，可包含：

```json
{
  "audience": "负责批准方案的业务负责人",
  "viewing": "presenter-led",
  "sources": ["inputs/source.pdf"],
  "visual_direction": "以具体产品照片和原生比较图表为主",
  "tokens": {
    "color_roles": {"background":"FFFFFF","text":"202124","accent":"276B64"},
    "typography": "按已核实可用的中英文字体安排标题、正文和图注",
    "grid": "共享左边距；图注与证据对象紧邻"
  },
  "slides": [
    {"page":1,"job":"说明比较对象","evidence":"原材料中的产品范围","visual":"真实产品图","layout_reason":"让对象先被识别"}
  ]
}
```

这是字段示例，不是强制内容或默认配色。计划不必逐项穷举，保留足够信息让长稿在中断后可以继续。简单改字无需创建。

## 参考库的使用

`reference_library.py` 提取参考 PPTX 的声明主题、版式占位符、原始媒体与逐页对象清单。结合渲染图建立：

- 品牌变量：字体角色、颜色角色、标识与使用方式。
- 风格规则：图片语言、图表处理、标题尺度、留白和密度。
- 版式用途：比较页、趋势页、方法页、封面等适合什么内容。

脚本不会自动完成这三种语义归类，也不会解析所有母版继承。把声明主题与实际视觉对照，识别大量直接覆盖样式的稿件。一个参考文件可能有多个主题，不能随意取第一个当全稿规则。

复用规则与素材应按用户要求及授权范围进行。使用模板时优先保持原生文件结构；只提取风格方向时，可用本包 JSON 主题与母版生成新稿。不要把“提取了主题”声称为任意版面像素级复刻。

## 从单次制作进化为可复用工程

主题、母版和素材组织在 `deck.json`、`assets/` 与 `inputs/`。不同稿件可复制经过验证的主题/母版配置，再按内容重新设计页面。沿用的是角色与规则，不是强制每页相同卡片。

每次重大重设计先看普通正文页与困难页，再扩展全稿。保留用户喜欢的设计；只有缺陷或新需求支持时才改规则，避免每次运行随机换风格。
