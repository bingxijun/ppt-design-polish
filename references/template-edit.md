# 已有稿、参考模板与内容保留

## 选择损失最少的路径

- 精确模板改字：优先保持原文件与对象，仅修改指定文字。
- 美化已有稿：保持事实、页数、顺序、原生图表/表格、备注与重要特殊对象，再重排必要对象。
- 重构故事：按用户授权改写和重组，但保留事实与显式输出要求。

未变动页、母版、动画、关系、嵌入工作簿和未知对象不应为了方便而重建。能够处理这些对象的原生编辑器优先；不支持时明确具体损失，保留源文件。不能只把 SmartArt 转成图片然后宣称其仍可编辑。

## 本包的精确文本补丁

```bash
python3 "<SKILL_ROOT>/scripts/patch_template.py" "/absolute/source.pptx" \
  --changes "/absolute/work/changes.json" --output "/absolute/work/revised.pptx"
```

`changes.json` 是数组：

```json
[{"slide":2,"shape_id":"5","old":"2025 年经营回顾","new":"2026 年经营回顾"}]
```

页码按演示顺序；`shape_id` 来自原始 XML 的 `cNvPr id`，可省略但必须唯一匹配。每项只替换一个现有 `a:t` 文本节点，保留 run 格式与其他对象；跨多个 run 的整段替换会拒绝匹配，需用宿主原生编辑器按 run 修改。不要拆掉格式硬拼字符串。

输出必须是新的文件。未修改 ZIP 条目的内容字节保持一致；修改页使用保留命名空间前缀的 DOM 序列化。更长文本仍可能溢出，因此补丁成功后必须重渲染与看图。本工具不负责重排、编辑图表数据或修改继承样式。

## 只美化的保留检查

将原文件副本放入 `inputs/source.pptx`，在 `contract.json` 写入：

```json
{"preserve_from":"inputs/source.pptx","required_text":{},"min_objects":{}}
```

`verify/finalize` 检查源稿页数、逐页文字与备注的空白规范化包含关系，检查原生图表/表格/SmartArt 链接数量，并核查图表缓存中的数值与标签仍存在。它不会证明工作簿公式、图解含义、链接有效性、动画顺序或视觉完全等价。还要回读源数据和检查实际对象。

模板填充主动改变了文字，不应同时开启“原文全部保留”。改用逐页 `required_text` 和必要的 `min_objects`，然后核查未改动对象。对重要复杂对象可以比较相关 ZIP 条目是否保持不变。

参考模板只作为风格参考时，原稿文字不是新稿事实来源。先分清“内容来源”和“视觉来源”，不要把模板里的旧数字带进新稿。
